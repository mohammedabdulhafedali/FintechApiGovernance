POST /v1/transfers

تنفيذ عملية تحويل مالي لحظي بين حسابين بنكيين مع التحقق الفوري من الرصيد والحدود.

مخطط البيانات المطلوب (TransferRequest Payload):

اسم الحقل النوع إلزامي؟ الوصف
sourceAccount string نعم رقم الحساب أو الآيبان للمرسل
destinationAccount string نعم رقم الحساب أو الآيبان للمستلم
amount number نعم المبلغ المراد تحويله (بحد أقصى 50,000 ريال)

قوانين العمل المصرفية الصارمة (Banking Rules):

⛔ BR_FIN_001 (شرط حرج - BLOCKING) request.amount <= 50000

الحد الأقصى للعملية الفورية الواحدة هو 50 ألف ريال وفق لوائح البنك المركزي.
