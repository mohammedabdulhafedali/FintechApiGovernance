تنفيذ عملية تحويل مالي لحظي بين حسابين بنكيين مع التحقق الفوري من الرصيد والحدود المالية وقواعد مكافحة غسل الأموال.

مخطط البيانات المطلوب (TransferRequest Payload):

اسم الحقل النوع إلزامي؟ الوصف
sourceAccount string نعم رقم الحساب أو الآيبان للمرسل
destinationAccount string نعم رقم الحساب أو الآيبان للمستلم
amount number نعم المبلغ المراد تحويله (سقف 50,000 ريال)

قوانين الحوكمة الصارمة (Banking Compliance):

⛔ BR_FIN_001 (شرط إلزامي - BLOCKING) request.amount <= 50000

الحد الأقصى للعملية الفورية الواحدة هو 50 ألف ريال وفق تعليمات البنك المركزي.
