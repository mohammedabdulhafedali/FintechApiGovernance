POST /v1/transfers

تنفيذ عملية تحويل مالي لحظي بين حسابين بنكيين مع التحقق الفوري من الرصيد والحدود المالية وقواعد مكافحة غسل الأموال (AML).

عقد البيانات المطلوب (TransferRequest Payload): مدعوم بتصنيف الامتثال المصرفي

اسم الحقل النوع إلزامي؟ تصنيف الامتثال المصرفي الوصف
sourceAccount string (IBAN) نعم PCI-Masked رقم الآيبان البنكي للمرسل (معتمد في ISO 20022)
destinationAccount string (IBAN) نعم PII Sensitive رقم الآيبان البنكي للمستلم
amount number نعم Financial/Audit المبلغ المراد تحويله (سقف 50,000 ريال)
idempotencyKey UUID v4 نعم Anti-Replay مفتاح فريد لمنع تكرار العملية والخصم المزدوج

مولد كود الربط الرسمي المعتمد (Multi-Language SDK):

// Spring Boot WebClient with HMAC Signature
TransferResponse response = webClient.post()
    .uri("https://ips.centralbank.gov/v1/transfers")
    .header("X-Signature-SHA256", HmacSigner.sign(payload, secretKey))
    .header("X-Idempotency-Key", UUID.randomUUID().toString())
    .bodyValue(transferPayload)
    .retrieve()
    .bodyToMono(TransferResponse.class)
    .block();
