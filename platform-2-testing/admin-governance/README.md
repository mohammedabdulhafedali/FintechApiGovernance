# Platform 2: Testing Engine & Simulation Governance

نظام الحوكمة والإدارة الخاص بمنصة الاختبارات والمحاكاة (`platform-2-testing`).

## مجالات الحوكمة الخاصة بالمنصة:

1. **قواعد تنفيذ الاختبارات (test-execution-rules/)**:
   - صلاحيات وسياسات إطلاق مجموعات الاختبارات الثقيلة (Load Testing / Stress Testing / Concurrency).
   - تحديد الحصص (Quotas) ومعدل الطلبات لتجنب الضغط غير المصرح به على بيئات المحاكاة.

2. **حوكمة البيانات الوهمية (mock-data-governance/)**:
   - عزل بيانات الفحص ومنع تسريب بيانات حقيقية حساسة إلى بيئات الاختبار (PII / Real Card Data).
   - اعتماد مولدات البيانات الوهمية (Mock Providers) وسيناريوهات الفشل الإيجابي والسلبي.

3. **اعتماد المطابقة والنتائج (compliance-validation/)**:
   - حوكمة معايير النجاح والرسوب (Pass/Fail Thresholds) لتقارير الامتثال الفني والمالي.
   - اعتماد شهادات اجتياز فحص الـ API قبل ترقيتها لبيئة الإنتاج.

4. **سجل التدقيق (audit-trail/)**:
   - تسجيل عمليات تشغيل الاختبارات، التجاوزات اليدوية للنتائج، وتاريخ تقارير المحاكي.
